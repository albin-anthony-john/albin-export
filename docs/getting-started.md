# Getting started

## 1. Install packages

```bash
dotnet add package Albin.Export
dotnet add package Albin.Export.Csv
dotnet add package Albin.Export.Excel
dotnet add package Albin.Export.Pdf
dotnet add package Albin.Export.AspNetCore
```

Add only the format packages the application actually serves.

## 2. Register exporters

```csharp
builder.Services.AddAlbinExport(export => export
    .AddPdf()
    .AddExcel()
    .AddCsv()
    .AddJson()
    .AddZip());
```

`IExportService` is registered as a singleton. Each `AddX()` registers one `IExporter`.

## 3. Prepare data in the application

Albin.Export does not load data. The application queries its own store and maps to DTOs:

```csharp
public sealed record SalesRow(string Region, decimal Revenue, DateTime Date);

var rows = await db.Sales
    .Where(x => x.Year == year)
    .Select(x => new SalesRow(x.Region, x.Revenue, x.Date))
    .ToListAsync(cancellationToken);
```

## 4. Export

Simplest path — columns come from public properties:

```csharp
var result = await export.ExportAsync(rows, ExportFormat.Csv, cancellationToken: cancellationToken);
return File(result.Stream, result.ContentType, result.FileName);
```

Explicit columns (preferred for reports and AOT):

```csharp
var table = ExportTable.Create(rows, "Sales")
    .Column("Region", x => x.Region)
    .Column("Date", x => x.Date, format: "yyyy-MM-dd")
    .Column("Revenue", x => x.Revenue, format: "N2")
    .Build();

var result = await export.ExportAsync(
    ExportDocument.FromTable(table, "Sales"),
    ExportFormat.Excel);
```

Full document (PDF, Word, HTML, Markdown):

```csharp
var document = ExportDocument.Builder("Sales report")
    .Subtitle("Confidential")
    .Footer("Generated by Contoso")
    .Paragraph("Figures are in USD.")
    .Table(table)
    .Build();

var result = await export.ExportAsync(document, ExportFormat.Pdf, new PdfExportOptions
{
    FileName = "sales",
    Landscape = true,
});
```

## 5. Return the file

MVC:

```csharp
return File(result.Stream, result.ContentType, result.FileName);
```

Minimal APIs:

```csharp
return result.ToHttpResult();
```

ASP.NET Core disposes the stream after the response is sent. Dispose the result yourself only when you do not hand the stream to the framework.

## Without dependency injection

```csharp
var export = new ExportService([new CsvExporter(), new ExcelExporter()]);
await using var result = await export.ExportAsync(rows, ExportFormat.Csv);
```
